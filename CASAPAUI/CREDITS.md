# FORME credits

FORME is a Riadly property theme created in October 2026. Its independent visual design, publication identity, interactive property index, schematic service plan, layouts, editorial copy and animation choreography were created for this theme. Established filtering, saving, dialog and form helpers are adapted from the workspace's SOLA implementation.

## Original demonstration photography

Codex's built-in image-generation tool produced four fictional assets:

- `assets/courtyard-house.webp`: sculptural concrete courtyard residence.
- `assets/ridge-house.webp`: weathering-steel and concrete desert retreat.
- `assets/pacific-house.webp`: cedar coastal home among cypress trees.
- `assets/alex-morgan.webp`: entirely fictional property advisor.

Each includes an `-800.webp` responsive version. WebP encoding and resizing preserve the original compositions; CSS crops the assets for each layout. Original generated PNGs remain in the workspace's `artwork/` folder outside the delivery ZIP. `artwork/PROMPTS.json` contains the exact four prompts and generation method.

The properties, specifications, advisor identity, contact details and explicitly labelled client-story examples are fictional. These images do not depict real listings. Identify the use of AI-generated demo imagery in product listings; replace it with accurate, authorized imagery for an actual agency. Sample quotes must not be presented as genuine testimonials.

## Fonts

Bricolage Grotesque (display), Inter (body) and JetBrains Mono (annotations) are self-hosted. Original Latin-subset files and their SIL Open Font License notices were reused from the workspace's Edmund font bundle. The notices are included in `assets/fonts/` and must stay with redistributed font assets.

The theme loads no remote fonts, trackers or animation libraries. The product cover and motion preview are captures/compositions of the implemented browser UI.

## Delivery locations

The compressed demonstration images and required font notices are in `assets/`. Original PNG artwork references above describe provenance; PNG masters and internal generation paths are not included. Any separate original prompt records are in `artwork/`. The HTML delivery uses the included WebP files and needs only Node.js to rebuild.
